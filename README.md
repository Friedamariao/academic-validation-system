# Academic Validation System

Academic Validation System (AVS) is a desktop application designed to validate student information and structured academic documents through the application of computational theory.

This project is being developed as part of the Computational Theory course at Universidad Politécnica de San Luis Potosí (UPSLP).

## Project Overview

The main objective is to demonstrate how formal languages, regular expressions, finite automata, context-free grammars, pushdown automata, and graph theory can be applied to practical validation problems in an academic environment.

## Planned Features

- Student registration and login.
- Student information validation.
- Academic identifier recognition using finite automata.
- Structured academic document validation.
- Nested structure recognition using pushdown automata.
- Document hierarchy analysis using graphs.
- Validation results and error messages.

## Computational Theory Concepts

| Concept | Application |
|---|---|
| Formal Languages | Definition of valid input formats |
| Regular Expressions | Student information validation |
| NFA | Academic identifier recognition |
| DFA | Deterministic string validation |
| Context-Free Grammars | Academic document syntax |
| Pushdown Automata | Nested structure validation |
| Graph Theory | Document hierarchy and relationship analysis |

## Scope and Limitations

AVS is an educational prototype. Student accounts and processed information are stored temporarily in memory during execution.

The application does not require a database, an external backend, or a connection to an official university system.
